# 组合权限的变更核准与受控试用

政策试用所用的合作社身份、资源条件域和提议。规则和请求都使用合成标识。

## 数据接口

各来源用 UTF-8 的 JSON 数组交付，各文件保留来源自己的标识。索引给出各路资料的归属。逗号连接的字段表示同一记录中的多项取值，`null` 表示来源没有提供相应信息。时间字段采用索引所列起点后的分钟数；事件先后按相关来源给出的时刻理解，数组位置仅用于陈列。所有人员、机构和业务编号仅供本地演练。
字段名用原系统的英文约定。请求状态以各端交付的原始记录为准，包含证据引用的字段并非可用凭据。

| 文件 | 来源 | 约定 |
| --- | --- | --- |
| `directory.json` | 机构身份目录 | 目录中的角色与当前生效事实相联系。 |
| `condition_domain.json` | 接口协议登记 | 条件域列出当前及将来可合法出现的资源类别、操作、用途及归属组合。 |
| `rules.json` | 安全平台主管 | 规则冲突时明确拒绝优先；未知标签仅在明确为该状态授权时可用。 |
| `edges.json` | 角色关系 | child 可继承 parent，对关系的编辑权限单独划定。 |
| `admin_scopes.json` | 安全授权人 | may_edit 指明可编辑的政策项类型，stages 为可操作试用或撤回的范围。 |
| `proposals.json` | 政策登记台 | 提议提出一种政策变化；detail 是要登记的事实字段。 |
| `resource_labels.json` | 报表接口 | owner 和 label 分别为实际登记归属和当前标签。 |
| `observations.json` | 报表入口 | 记录可作为业务请求回放输入，不记录任何预定授权结果。 |
| `activations.json` | 各租户报表服务 | 状态描述实际接入申请及服务确认；revision 表示该端应用的政策资料引用。 |

## 本地运行

使用 Python 3.11 标准库。启动只读资料服务后可查看各来源当前准备好的输入文件：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory feeds
```

资料目录为 `http://127.0.0.1:8765/index.json`。

```sh
python3 -m unittest discover -s tests -v
```

测试核对演练资料的字段、索引及来源间的引用。
