# 组合权限的变更核准与受控试用

政策试用所用的合作社身份、资源条件域和提议。规则和请求都使用合成标识。

## 数据接口

各来源用 UTF-8 的 JSON 数组交付，各文件保留来源自己的标识。索引给出各路资料的归属。逗号连接的字段表示同一记录中的多项取值，`null` 表示来源没有提供相应信息。时间字段采用索引所列起点后的分钟数；事件先后按相关来源给出的时刻理解，数组位置仅用于陈列。所有人员、机构和业务编号仅供本地演练。
字段名用原系统的英文约定。请求状态以各端交付的原始记录为准，包含证据引用的字段并非可用凭据。

| 文件 | 来源 | 约定 |
| --- | --- | --- |
| `directory.json` | 机构身份目录 | 目录中的角色与当前生效事实相联系。 |
| `condition_domain.json` | 接口协议登记 | 条件域列出当前及将来可合法出现的资源类别、操作、用途及归属组合。 |
| `rules.json` | 安全平台主管 | 规则冲突时明确拒绝优先；未知标签仅在明确为该状态授权时可用。 |
| `edges.json` | 角色关系 | child 可继承 parent，对关系的编辑权限单独划定。 |
| `admin_scopes.json` | 安全授权人 | may_edit 指明可编辑的政策项类型，stages 为可操作试用或撤回的范围。 |
| `proposals.json` | 政策登记台 | 提议提出一种政策变化；detail 是要登记的事实字段。 |
| `resource_labels.json` | 报表接口 | owner 和 label 分别为实际登记归属和当前标签。 |
| `observations.json` | 报表入口 | 记录可作为业务请求回放输入，不记录任何预定授权结果。 |
| `activations.json` | 各租户报表服务 | 状态描述实际接入申请及服务确认；revision 表示该端应用的政策资料引用。 |

## 本地运行

使用 Python 3.11 标准库。启动只读资料服务后可查看各来源当前准备好的输入文件：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory feeds
```

资料目录为 `http://127.0.0.1:8765/index.json`。

```sh
python3 -m unittest discover -s tests -v
```

测试核对演练资料的字段、索引及来源间的引用。

## 权限核准与受控试用项目

`agri_policy/` 把拟定变更、验证与接口实际授权接进一个可继续操作的项目，
直接读取上述资料（不修改原始 JSON）。核心行为：

- **政策求值**：显式拒绝优先于允许；未知标签只有在明确为 unknown 状态授权时
  可用；未落在 `condition_domain.json` 已登记条件域内的组合为 `undefined`。
- **授权范围**：管理员只能编辑其 `may_edit` 覆盖的政策项，且限于本机构名下的
  账号与资源；不能把本机构账号改成另一家企业专有的角色，也不能改写资源归属。
- **影响分析**：按政策中全部角色比较能力，而非当前恰好持有角色的人。两项独立
  提交、依赖同一条继承关系的提议，会报出叠加后才打开的能力及其角色、操作、
  资源类别。
- **受控试用**：已核准提议只对试用覆盖的「租户 + 用途」放量；其余租户与用途
  继续使用原政策。身份所属机构必须与请求租户一致，不跨两边政策各取一半。
- **漂移复核**：角色继承、标签归属或目录事实被独立修改后，按能力与具体资源
  访问面重算，只暂停超出核准约定的部分；仍落在约定内的继续办理。判定不参考
  是否观察到访问。
- **撤回**：只移除该试用自身带来的新增权利；独立决定要停用的访问不随之恢复。
- **审计**：已产生的接口决定保留当时的身份、所用政策修订与结果，不因后续政策
  变化而改写。

### 本地操作

```sh
# 列出提议检查与项目状态
python3 -m agri_policy.cli summary
# 两项独立提议叠加后新打开的授权
python3 -m agri_policy.cli stacked
# 值班员按角色定位变化来源（提议自身 / 叠加 / 新的目录事实）
python3 -m agri_policy.cli locate --role staged-analyst
# 以合作社身份查询一次业务资料
python3 -m agri_policy.cli request --person u4 --tenant coop-a \
    --resource rs-1 --operation read --purpose settle
# 端到端演练
python3 examples/scenario.py
```

### 测试

```sh
python3 -m unittest discover -s tests -v
```

`tests/test_policy.py` 覆盖政策求值、管理员范围、叠加分析、试用隔离、漂移
部分暂停、撤回保持独立停用，以及三类查询视图的可见范围。
